# ⚖️ LegalEase

**Pakistan's first AI-powered contract analysis tool**

LegalEase uses 4 AI agents to analyse contracts, flag risky clauses in English and Urdu, and rewrite them into fair versions — in under 10 seconds.

## Features
- 🔍 4-agent AI pipeline
- 🔴 Risk detection (HIGH / MEDIUM / LOW)
- 🇵🇰 English and Urdu explanations
- ✏️ Safe clause rewriting
- 📄 PDF download
- 👤 User accounts and history
- 💳 Free tier + Pro plan

## Tech Stack
- Frontend: Streamlit
- AI: Groq (LLaMA 3.3 70B)
- Database: Supabase
- PDF: FPDF2
